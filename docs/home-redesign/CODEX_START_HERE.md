## 先讀：最重要的原則

1. **保留現有正式官網的深色背景和品牌視覺**。使用現有程式碼中的色彩 token、元件、Logo 與真實角色素材；不要把 `reference/home_hifi_light_reference.html` 的淺色主題照搬到正式站。
2. **Podcast 是主要轉換目標**：讓家長快速找到節目、前往 Apple Podcasts / Spotify 收聽或追蹤。
3. **以最少額外維護為原則**。重用現有 Podcast 更新 workflow、伴讀資料、遊戲資料，不重新建系統。
4. **不要破壞既有功能**：伴讀網址、遊戲、登入、關卡進度、徽章、原有 API、排程、SEO 等須保留。

6. 如果設計稿和現有深色官網有衝突，**以本文件的功能需求及現有深色品牌為準**；設計稿只作版型、區塊順序與互動參考。

## 首頁資訊架構（此順序已定案）

### 01｜Hero
- 品牌標語「永遠對世界抱持好奇心」及短品牌介紹。
- 主要 CTA：開始收聽 Podcast；次 CTA：探索科學。
- 右側 2–3 張人工精選卡片，**自動輪播＋可手動切換**（V1.2 變更，見文末「變更紀錄」）：
  - 預設每 6 秒切換一張，秒數可在內容資料中設定（`autoplaySeconds`，0 = 關閉自動輪播）。
  - 必須提供暫停／繼續按鈕；滑鼠移入或鍵盤焦點在輪播內時暫停；手動切換後重新計時。
  - 使用者系統開啟「減少動態效果」（prefers-reduced-motion）時不自動輪播。
- 可編輯欄位：標題、圖片、簡述、連結、顯示狀態、排序。
- 後續使用 Google Sheets 作編輯介面，透過安全的資料同步產出公開 JSON；不可將 Sheets 憑證暴露於前端。

### 02｜Podcast（首頁的最大核心內容區）
- 顯示**最新 5 集**，封面、集數、標題、日期、時長、收聽連結。
- 可搜尋節目標題、集數、簡介；需要確認現有資料是否包含全部歷史集數。
- 不做人工主題分類，也不要求維護者每天幫節目分類。
- Apple Podcasts、Spotify 的收聽/追蹤入口清楚可見；沿用既有 RSS / 串流擷取 workflow。
- 搜尋結果應有 Loading、Empty、Error、可鍵盤操作的狀態；不要讓搜尋假裝能查全部集數，若只能查現有資料要清楚標明。

### 03｜互動科學探索館
- 首頁人工精選 **2–4 個作品**，顯示封面、名稱、簡介、連結。
- 初期兩個作品為太陽系探索室與台北 101 風雨實驗室。
- Google Sheets 作品資料可含：id、title、description、coverImage、url、status、featured、sortOrder。
- 未來可能達到 136 個作品，因此資料結構需可擴充。
- **完整探索館列表頁、搜尋與分類目前 Pending，這次不要開發。**

### 04｜Solar Star
- 9:16 YouTube 嵌入播放器（實際影片需有合法 YouTube ID 才能播放）。
- 一支主影片，旁邊列 3 支可切換精選影片；點選後在同一區塊播放。
- 不自動播放；採影片縮圖延遲載入／點擊後載入 iframe；使用適當隱私模式。
- 提供前往 YouTube 播放清單或頻道的入口。
- 優先從現有設定/影片清單取得 IDs；沒有 IDs 時顯示可操作的空狀態，不捏造實際連結。

### 05｜更多親子學習資源
- 上半：從既有科普伴讀資料**每天固定隨機選 3 篇**（當日一致），顯示真實封面、集數、標題、閱讀入口。
- 下半：展示 **3 個真實可玩的關卡**，原則上七彩氣球／知識接接樂／尋寶獵人各一個，可直接進到對應關卡（若目前路由不支援，需先列出限制）。
- 保留伴讀列表及遊戲基地的獨立入口；不另外建管理系統。

### 06｜品牌形象＋Footer（B 方案）
- 使用既有好奇博士與科學隊長角色圖，非創辦人個人照片。
- 簡述品牌故事，保留「科學爸爸 Kyle／台大博士創辦」及「Apple Podcasts 科學類冠軍」等正確專業背書。
- Footer：Podcast、互動網站、Solar Star、伴讀、遊戲、Facebook、YouTube、Email。
- 尊重現有 Logo 與角色設計，不額外改造 IP。

## 重要跨區塊需求

- 桌機與手機版都需可用；手機按鈕可觸控、圖文清晰、不得有水平溢出。
- 深色設計下須保證文字可讀、對比足夠、焦點樣式清楚；避免大面積強烈炫光效果。
- 不要一次同步讀取或嵌入大量影片，顧及效能、Core Web Vitals、SEO。
- 避免空連結與假按鈕；所有 CTA 應通往真實網址或對應站內功能。
- 可追蹤 `podcast_episode_click`、`podcast_platform_click`、`interactive_lab_click`、`solar_video_play` 等事件；事件命名應與現有 GA4 設定一致，不盲目重複植入 GA。
- Podcast 平台外連點擊 ≠ 真正成功追蹤／訂閱，分析時不可混為一談。
